# next-secure-check brand mark

The primary mark is the open interlock in [`../assets/next-secure-check-mark.svg`](../assets/next-secure-check-mark.svg).
It represents two release boundaries and a deliberate crossing path: code can move
quickly, while the next review step remains visible.

## Usage

- Use the SVG mark on dark navy (`#0B1220`) or a plain light background.
- Keep the two-color version at 24 px or larger. For one-color contexts, use the
  same geometry in a single solid color.
- Keep clear space around the mark equal to at least one stroke width.
- Pair the mark with the lowercase wordmark `next-secure-check`.
- Use the campaign line **Vibe code fast. Ship with context.** in launch materials.

## Boundaries

The mark deliberately avoids a shield, checkmark, padlock, eye, lightning bolt,
triangle, terminal prompt, mascot, and decorative gradient. It does not use or
modify the Next.js or Vercel marks. `next-secure-check` is an independent tool;
Next.js is referenced only to describe the supported project type.

The concept was generated with GPT Imagine and then rebuilt as deterministic SVG
geometry for crisp rendering in the README and campaign video. This is a design
provenance note, not a legal trademark clearance. A collision screen was run on
the exact product name and common security/developer logo patterns on 2026-09-05;
formal trademark clearance still requires a professional search in the target
markets before registration or paid advertising.
